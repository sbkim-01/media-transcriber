## 안정성 테스트

- 영상 100초/오디오 20초 파일: 기존 = RuntimeError("빈 오디오", 재실행해도 동일), v2 = 정상
- 문장부호만 있는 텍스트 정렬: 라이브러리는 항목 0개 반환 → 기존 스크립트 586행 RuntimeError 경로, v2 = 텍스트 보존
- 출력 토큰 한도 강제(256): 한도 도달 청크를 쉼 지점에서 2분할 재전사, 글자 수 1488 vs 정상 1495
- 강제 종료(timeout) 후 재실행: 완료 구간 2개 복원 후 이어서 완료, 체크포인트 정리
- OOM 모의: 배치 8→4→2 축소 후 같은 입력 재처리, 순서/개수 보존
- 정렬기 항목 실패 모의: 해당 항목만 정렬 비움(텍스트 보존), 나머지 정상
- 무음 15초 / 1.2초 파일 / VBR MP3: 정상
- 동일 설정 재실행 시 출력 바이트 단위 동일
- 문단 구성 회귀: 같은 레코드에 대해 기존/신규 format_paragraphs 결과 동일
